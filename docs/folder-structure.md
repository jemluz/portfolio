## 📂 File Naming

### Next.js Pages

```
src/app/
├── page.view.tsx           # Page component (separated view logic)
├── layout.tsx              # Layout component
└── background/
    ├── page.view.tsx       # Route-specific page view
    └── styles.css          # Route-specific styles
```

### Components

```
ComponentName.tsx           # PascalCase for components
component-name.types.ts     # kebab-case for supporting files
component-name.utils.ts
component-name.constants.ts
```
